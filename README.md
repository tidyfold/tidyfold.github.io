# tidyfold-site

Public website and privacy policy for the Tidyfold browser extension, served from Cloudflare Workers at https://tidyfoldapp.com (Workers Builds deploys on push; `wrangler.jsonc` holds the config). GitHub Pages at tidyfold.github.io still mirrors it.

- `index.html` — landing page
- `privacy/index.html` — privacy policy (linked from the Chrome Web Store listing)
